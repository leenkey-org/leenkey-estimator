# Type annoncé : titre de propriété

À extraire dans `key_facts` : la nature de l'acte (vente, donation, succession), la date d'acquisition, la désignation du bien dans ses grandes lignes (nature, lots, sans l'adresse), les servitudes mentionnées, les conditions particulières écrites (droit de préemption, usufruit, indivision) sans nommer les personnes.

Ne recopie ni le nom des parties, ni le prix d'acquisition, ni les références cadastrales, ni l'adresse.

Points d'attention : les servitudes, l'usufruit, l'indivision, les conditions particulières, tels qu'écrits. Tu ne dis pas ce qu'ils impliquent pour la vente : c'est le rôle du notaire.

`public_facts`, clé permise : `servitudes` (« Aucune mentionnée » si le document le dit).
