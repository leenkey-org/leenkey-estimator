# Type annoncé : procès-verbal d'assemblée générale de copropriété

À extraire dans `key_facts` : la date de l'assemblée, les travaux votés (nature, montant pour l'immeuble, échéance des appels), les travaux refusés ou reportés, les procédures en cours impliquant la copropriété, le montant des impayés de la copropriété s'il figure, le budget prévisionnel voté, les questions annoncées pour une prochaine assemblée.

Points d'attention : les travaux votés non encore appelés, les procédures, les impayés, les sujets reportés. Ne nomme aucun copropriétaire, y compris débiteur ou partie à une procédure : écris « un copropriétaire ».

`public_facts`, clé permise : `travaux_votes`, `"oui"` si l'assemblée a voté des travaux, `"non"` si le procès-verbal n'en vote aucun.
