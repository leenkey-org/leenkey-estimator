# Type annoncé : état des risques (ERP)

À extraire dans `key_facts` : les risques recensés pour le bien (naturels, miniers, technologiques, sismicité et son niveau, potentiel radon et son niveau, recul du trait de côte, secteur d'information sur les sols), l'existence d'un plan de prévention et son état (prescrit, approuvé), les sinistres indemnisés déclarés, la date d'établissement.

Points d'attention : les risques pour lesquels le document indique que le bien est concerné, les prescriptions de travaux mentionnées, les sinistres déclarés.

`public_facts`, clé permise : `risques` (la liste courte des risques pour lesquels le bien est concerné, ou « Aucun risque recensé » si le document le dit).
